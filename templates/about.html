Objectives

  • Analyse attendance, assignment completion, revision and quiz scores.
  • Compare modules and learner groups.
  • Detect possible learning friction with transparent rules.
  • Suggest supportive, explainable recovery steps.
  • Propose a follow-up assessment process.

Methodology

  1. Create a small simulated dataset (CSV files).
  2. Calculate indicators and a combined score with Pandas and NumPy.
  3. Display results with Flask pages and Chart.js charts. Matplotlib makes Python charts.
  4. Build rule-based friction detection in Python.
  5. Explain every recommendation in plain language.

Technologies

HTML5 CSS3 Vanilla JavaScript Python Flask Pandas NumPy Chart.js Matplotlib CSV Git & GitHub

Limitations

  • Only five simulated students and a synthetic module dataset. Results are illustrations.
  • The combined score and friction index use experimental weights that are not validated.
  • The prototype is rule-based. It is not a trained machine-learning model.
  • The follow-up assessment is a proposed feature, not tested with learners.
  • No real-time data, login system or database yet.
